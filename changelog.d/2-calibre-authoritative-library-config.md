### Added
- **Calibre/CWA authoritative-library mode — configuration and design contract** (#2) — an opt-in, default-off setting (`calibre.authoritative_library_enabled`, Settings → Calibre) stating that Calibre/CWA owns the metadata of the books it already holds, so Bindery reads `metadata.db` read-only rather than importing those books into its own catalogue. Existing Calibre behaviour is unchanged while it is off, and enabling it today records the choice only — owned-book matching and the metadata audit follow in later releases. The authority boundary and its invariants are documented in `docs/design/calibre-authoritative-library.md`.
