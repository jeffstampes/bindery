### Added
- **Calibre/CWA authoritative-library mode — configuration and design contract** (#2) — an opt-in, default-off setting (`calibre.authoritative_library_enabled`, Settings → Calibre) recording operator intent for Calibre/CWA to own the metadata of books it holds. Authoritative mode is designed to read `metadata.db` read-only instead of importing those books into Bindery's catalogue. Enabling the setting today records this configuration only; live owned-library reading, matching, and owned-state integration arrive in later slices and enabling the setting does not yet change catalogue or ownership behavior. The authority boundary and its invariants are documented in `docs/design/calibre-authoritative-library.md`.
